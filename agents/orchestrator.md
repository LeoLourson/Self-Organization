# Инструкция для сессии Claude Code, ведущей субагентов

Этот файл нужен только для запуска эксперимента на субагентах Claude Code. Ты пересылаешь сообщения
между `run.py` и субагентами-участниками, чтобы каждый агент держал весь запуск в одном разговоре.
Участники должны отвечать сами, поэтому не пиши за них, не правь и не дополняй их ответы и не подсказывай им.
Работай в корне проекта, а платные запуски начинай только по поручению пользователя.

## Что человек делает до сессии

1. `python run.py sandbox on` убирает пользовательские инструкции Claude Code.
2. `python run.py agent-file` записывает `.claude/agents/net-agent.md`.
3. Новая сессия Claude Code запускается в корне проекта, поскольку определения агентов читаются при старте.
4. После запусков `python run.py sandbox off` возвращает инструкции.

## Цикл одного запуска

1. `python run.py start --profile P --condition C --repeat N` выдаёт ID.
2. `python run.py advance --id ID` выдаёт `request` с полями `request_id`, `agent`, `agent_id`, `message`.
3. Если `agent_id` равен null, запусти нового субагента типа `net-agent` (Agent tool, `subagent_type: "net-agent"`)
   с промптом, равным `message` дословно. Иначе отправь `message` дословно существующему субагенту через
   `SendMessage(to: agent_id)`. Нового субагента вместо существующего не создавай: агент потеряет память.
4. Сохрани ответ в `runs/answers/REQUEST_ID.json`:

   ```json
   {"request_id": "...", "content": "ответ дословно",
    "execution": {"engine": "claude-code", "model": "<модель из request>", "agent_id": "<ID субагента>"}}
   ```

5. `python run.py submit --id ID --file runs/answers/REQUEST_ID.json`, затем снова шаг 2.
6. После итогов раундов `advance` сам проводит оба голоса, контрольные повторы и судью через API и субагентов
   больше не запрашивает. Для этого нужны ключ из профиля `vote_profile`, обычно `ANTHROPIC_API_KEY`, и `DEEPSEEK_API_KEY`.
   Повторяй `advance` до `done: true`. Ответ `phase: failed` означает три некорректных ответа подряд: сообщи пользователю.

Пять субагентов одного запуска используются только в нём, для следующего создаются новые. Запуски идут последовательно.

## После запусков

Допиши сверху в [Журнал.md](../Журнал.md) запись с датой, где укажи профиль и модель, условия и повторы, число завершённых
и проваленных запусков и отклонения от протокола.
