# Инструкция оркестратору (Claude Code)

Ты пересылаешь сообщения между `run.py` и субагентами-участниками. Не пиши за
участников, не правь и не дополняй их ответы, не подсказывай им. Рабочий каталог —
корень проекта. Платные прогоны запускай только по поручению пользователя.

## Перед сессией (делает человек)

1. `python run.py sandbox on` — убрать пользовательские инструкции Claude Code.
2. `python run.py agent-file` — записать `.claude/agents/net-agent.md`.
3. Запустить новую сессию Claude Code в корне проекта: определения агентов
   и инструкции читаются при старте сессии.
4. После прогонов — `python run.py sandbox off`.

## Цикл одного прогона

1. `python run.py start --profile P --condition C --repeat N` → ID.
2. `python run.py advance --id ID` → `request` с полями `request_id`, `agent`,
   `agent_id`, `message`.
3. Если `agent_id` равен null — запусти нового субагента типа `net-agent`
   (Agent tool, `subagent_type: "net-agent"`) с промптом, равным `message` дословно.
   Иначе отправь `message` дословно существующему субагенту через
   `SendMessage(to: agent_id)`. Нового субагента вместо существующего не создавай.
4. Сохрани ответ в `runs/answers/REQUEST_ID.json`:
   `{"request_id": "...", "content": "ответ дословно",
     "execution": {"engine": "claude-code", "model": "<модель из request>", "agent_id": "<ID субагента>"}}`
5. `python run.py submit --id ID --file runs/answers/REQUEST_ID.json`, затем снова п. 2.
6. После итогов раундов `advance` сам проводит голосование и судью через API
   (нужен ключ из профиля `vote_profile`, обычно `ANTHROPIC_API_KEY`, и `DEEPSEEK_API_KEY`)
   и субагентов больше не запрашивает. Повторяй до `done: true`.
   `phase: failed` — три некорректных ответа подряд; сообщи пользователю.

Пять субагентов одного прогона используются только в нём. Для следующего прогона
создаются новые. Прогоны выполняй последовательно.

## Завершение

Допиши в `Журнал.md` раздел с датой: профиль и модель, условия и повторы,
число завершённых и проваленных прогонов, отклонения от протокола.
