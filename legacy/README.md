# Архив: запуски прежних протоколов

Здесь хранятся данные экспериментов, проведённых до единого протокола с двумя голосами. По ним можно проверить
числа из [Журнал.md](../Журнал.md) и пересчитать отчёты командой `python run.py analyze --legacy`. С новыми сериями эти
запуски не смешиваются, поскольку у них другие промпты и другой формат голосования.

| Папка или файл | Что там |
|---|---|
| runs/results, runs/state | Итоги и состояния запусков |
| runs/revote, runs/probe | Голоса с причинами и повторы голоса на тех же историях |
| reports/ | Отчёты, написанные в момент запусков; в них прежняя терминология |
| requests.sqlite3 | Кэш ответов API и учёт расхода |
| Запуск_6B.md | Инструкция для локальных моделей через Ollama |
| tmp-tests/ | Рабочие скрипты и журналы серий; в git не входят |

Команды, собиравшие `runs/revote` и `runs/probe`, из кода удалены и остались в истории git.
